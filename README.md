# Geospatial Data Analysis with Python

An **open educational resource** — Python programming for geospatial data handling,
processing, visualization, and workflow automation. Starts from no assumed
programming experience.

By **Dr. Suborna Ahmed**, University of British Columbia.

**📖 Read the book:** https://subornaa.github.io/geospatial-data-analysis/

## Contents
Python foundations · programming logic & reusable code · tabular data (Pandas) ·
vector data (GeoPandas & Shapely) · CRS & data quality · ArcPy · raster analysis
(NumPy & Rasterio) · visualization · introductory machine learning. Each chapter
includes practice exercises.

A PDF edition is available from the **Download PDF** button on the site.

Recurring datasets: the Malcolm Knapp Research Forest (British Columbia), the
mangrove coast of northwest Madagascar, and Landsat imagery.
