Chapter 10 — Visualization & Communication

A result only matters if you can communicate it. This chapter: clear maps of vector and raster data, thoughtful classification and legends, and a short honest interpretation. Matplotlib is our main tool; GeoDataFrame.explore() gives one quick interactive map.

Run in Python (gem530).

Learning outcomes¶

  1. Plot vector data and make a classified choropleth with a legend.
  2. Display raster data and overlay vector on it.
  3. Add titles, labels, and an annotation.
  4. Plot an attribute summary (a chart from a table).
  5. Make one interactive map with .explore() and write a 3-sentence interpretation.

1. Plot vector data¶

GeoDataFrame.plot() draws geometries. Colour by a column to make a choropleth; scheme="quantiles" (via mapclassify) groups values into classes.

In [ ]:
import numpy as np
import geopandas as gpd
import matplotlib.pyplot as plt

# In the course: gdf = gpd.read_file("outputs/fires_bcalbers.gpkg") (Chapter 6 output).
# Small MKRF sample so the classification has enough values to show:
lons = np.linspace(-122.60, -122.48, 8)
lats = np.linspace(49.26, 49.34, 8)
gdf = gpd.GeoDataFrame(
    {"site": ["MKRF"] * 8, "area_ha": [5, 8, 12, 3, 20, 15, 7, 25]},
    geometry=gpd.points_from_xy(lons, lats), crs="EPSG:4326")

fig, ax = plt.subplots(figsize=(6, 6))
gdf.plot(ax=ax, column="area_ha", scheme="quantiles", k=4,
         legend=True, markersize=40, cmap="OrRd")
ax.set_title("Fire size by location (quantile classes)")
ax.set_axis_off()
plt.show()

🌲 Why code this? A map is how forestry results get used. Plotting straight from your GeoDataFrame means the figure always matches the data — no re-exporting to another program.

✅ Quick check — choropleth¶

What does column="area_ha" do in gdf.plot(column="area_ha", legend=True)?

▶ Show answer It colours each feature by its area_ha value (a choropleth) and draws a matching legend.

2. Display raster + overlay vector¶

Plot a raster with rasterio.plot.show, then draw vector features on the same axes so they line up (they must share a CRS).

In [ ]:
import rasterio
from rasterio.plot import show
from rasterio.transform import from_origin
from pathlib import Path
Path("data").mkdir(exist_ok=True)

# In the course: open a provided DEM (e.g. SRTM.tif). Here we make a small demo
# raster covering the sample points so the overlay lines up:
demo = np.random.default_rng(1).normal(300, 40, (20, 20)).astype("float32")
with rasterio.open("data/demo_elev.tif", "w", driver="GTiff", height=20, width=20,
                   count=1, dtype="float32", crs="EPSG:4326",
                   transform=from_origin(-122.62, 49.36, 0.008, 0.006)) as dst:
    dst.write(demo, 1)

fig, ax = plt.subplots(figsize=(6, 6))
with rasterio.open("data/demo_elev.tif") as src:
    show(src, ax=ax, cmap="terrain")                              # raster backdrop
    gdf.to_crs(src.crs).plot(ax=ax, color="red", markersize=30)  # overlay
ax.set_title("Fire points over elevation")
plt.show()

🌲 Forestry example. Stands over a hillshade, fire points over burn severity — overlaying vector on raster is how you show where something happened, in context.

✅ Quick check — overlays¶

Two layers plot in the same figure but don't line up. First thing to check?

▶ Show answer Their CRS. Reproject one to match the other (gdf.to_crs(other.crs)) and draw both on the same ax.

3. Titles, labels, annotation¶

Every analytical map needs a title, a legend, and often one annotation pointing at the key feature.

In [ ]:
fig, ax = plt.subplots(figsize=(6, 6))
gdf.plot(ax=ax, column="area_ha", legend=True, markersize=40, cmap="OrRd")
ax.set_title("Burned area by fire (ha)")
# annotate the largest fire
biggest = gdf.loc[gdf["area_ha"].idxmax()]
ax.annotate("largest fire",
            xy=(biggest.geometry.x, biggest.geometry.y),
            xytext=(10, 10), textcoords="offset points",
            arrowprops=dict(arrowstyle="->"))
plt.show()

🌲 Why code this? A title, legend and one annotation are the difference between a plot only you understand and a figure that stands alone in a report.

4. Plot an attribute summary¶

Sometimes a chart communicates better than a map. Pandas plots straight from a summary table.

In [ ]:
by_site = gdf.groupby("site")["area_ha"].sum()
by_site.plot(kind="bar", title="Total burned area per site (ha)")
plt.ylabel("area (ha)")
plt.tight_layout()
plt.show()

🌲 Forestry example. Sometimes a bar chart of area-by-species communicates better than a map. Choose the form that answers the question.

5. One interactive map¶

GeoDataFrame.explore() builds an interactive (Folium/Leaflet) map with one line — you don't need to learn Folium's API. Good for exploring; static maps are still best for reports.

In [ ]:
m = gdf.to_crs(4326).explore(column="area_ha", cmap="OrRd", legend=True)
m   # displays an interactive, zoomable map in the notebook

🌲 Why code this? An interactive map lets a colleague zoom to their own management unit — perfect for exploration and review meetings.

6. Communicate the result¶

A map needs words. Write 3 sentences: what the map shows, one pattern you see, and one limitation (e.g. small sample, missing data, class choices affect the look).

Try it yourself. Change the choropleth to k=3 classes and a different cmap. Does the story the map tells change? That's why classification choices must be reported.

🌲 Why code this? Stating the pattern and a limitation is what makes a map honest. Class breaks and colour choices can exaggerate — say what you chose.

Common errors this chapter (and the fix)¶

Symptom Cause Fix
layers don't overlap different CRSs gdf.to_crs(other.crs) and share one ax
no legend appears forgot legend=True add it (and column=)
map is unreadable too many classes / harsh colours fewer classes, a sequential colormap
figure cut off when saved tight elements plt.savefig(..., bbox_inches="tight")

🎓 Additional learning (optional)¶

Bonus 1 — Save a report-quality figure¶

Why code this? A screenshot won't survive a report. savefig with a sensible DPI gives you a crisp, embeddable figure.

In [ ]:
import geopandas as gpd, matplotlib.pyplot as plt
from shapely.geometry import box
from pathlib import Path
g = gpd.GeoDataFrame({"v": [1, 2]}, geometry=[box(0,0,1,1), box(1.2,0,2,1)], crs="EPSG:3005")
ax = g.plot(column="v", legend=True, edgecolor="black")
ax.set_title("Example stand map"); ax.set_axis_off()
Path("outputs").mkdir(exist_ok=True)
plt.savefig("outputs/stand_map.png", dpi=300, bbox_inches="tight")
plt.close()
print("wrote outputs/stand_map.png (300 dpi)")

Bonus 2 — Before / after side by side¶

Why code this? Change is the story in forestry — harvest, fire, regrowth. Two panels sharing a colour scale let a reader compare dates honestly.

In [ ]:
import numpy as np, matplotlib.pyplot as plt
before = np.array([[0.8, 0.7], [0.75, 0.85]])
after  = np.array([[0.3, 0.65], [0.20, 0.80]])
fig, axes = plt.subplots(1, 2, figsize=(7, 3))
for ax, arr, name in zip(axes, [before, after], ["Before", "After"]):
    im = ax.imshow(arr, vmin=0, vmax=1, cmap="YlGn")   # same scale on both!
    ax.set_title(name); ax.set_axis_off()
fig.colorbar(im, ax=axes, label="NDVI", shrink=0.8)
plt.show()

🌲 Note vmin/vmax — using the same scale on both panels is what makes the comparison fair.

Packages used this chapter¶

  • Matplotlib — the primary plotting tool: maps, overlays, legends, annotations, charts. Geospatial link: renders both vector (via GeoPandas) and raster (via Rasterio) results.
  • GeoPandas .plot / .explore — choropleths and one-line interactive maps (.explore uses Folium under the hood, so we don't teach Folium separately).
  • mapclassify — classification schemes (quantiles, equal_interval) for choropleths. See the Package Guide.

Working with AI (30-second habit)¶

AI makes plausible plotting code, but check: does the legend match the data, is the CRS consistent for overlays, and are the class breaks honest (not chosen to exaggerate)? Misleading maps are easy to make by accident.
