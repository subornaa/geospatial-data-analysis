Chapter 3 — Tabular Data with Pandas

Most environmental data arrives as tables — plots, fire records, field measurements. Pandas is the tool for loading, cleaning, filtering, and summarizing tables in Python. Its main object is the DataFrame.

Learning outcomes¶

  1. Create/read a DataFrame and inspect it (head, info, describe).
  2. Select, filter, and sort rows and columns.
  3. Add a computed column and handle missing values.
  4. Group and summarize with groupby.
  5. Join two tables with merge.
  6. Sanity-check coordinate columns and export cleaned data. Kernel: Python (gem530).

1. A DataFrame¶

A DataFrame is a table: named columns, numbered rows. Here is a small fire-occurrence table (like Canada's National Fire Database).

In [ ]:
%matplotlib inline
import pandas as pd

data = {
    "site":   ["MKRF", "MKRF", "Ambaro", "Ambaro", "MKRF", "Ambaro"],
    "year":   [2019, 2020, 2019, 2021, 2021, 2020],
    "lat":    [49.27, 49.29, -13.35, -13.40, 49.31, -13.33],
    "lon":    [-122.57, -122.55, 48.55, 48.60, -122.52, 48.58],
    "area_ha":[12.5, 3.0, 40.0, None, 7.5, 22.0],   # note the missing value
    "cause":  ["lightning", "human", "human", "human", "lightning", "lightning"],
}
df = pd.DataFrame(data)
df.head()
In [ ]:
df.info()      # column names, types, and non-null counts
df.describe()  # quick numeric summary

🌲 Why code this? A DataFrame is a forest-inventory table in code — plots as rows, measurements as columns — that you can filter, summarise, and join far faster and more reliably than a spreadsheet.

2. Select, filter, sort¶

In [ ]:
# select columns
print(df[["site", "area_ha"]].head())

# filter rows: only lightning fires
lightning = df[df["cause"] == "lightning"]
print("\nLightning fires:")
print(lightning)

# sort by area, largest first
print("\nSorted by area:")
print(df.sort_values("area_ha", ascending=False).head())

🌲 Forestry example. Filtering pulls out just the fir plots, or fires over 100 ha; sorting ranks stands by volume. One line replaces scrolling and highlighting cells.

✅ Quick check — filtering¶

Which expression keeps only the rows where species is "fir"?

▶ Show answer df[df["species"] == "fir"] — a boolean filter keeps the rows where the condition is True.

3. New columns & missing values¶

area_ha has a missing value (NaN). We can fill or drop it, and we can compute a new column.

In [ ]:
# a computed column: area in square kilometres
df["area_km2"] = df["area_ha"] / 100.0

# how many missing?
print("Missing area_ha:", df["area_ha"].isna().sum())

# fill missing area with 0 (a choice you must justify!)
df["area_ha"] = df["area_ha"].fillna(0)
df[["site", "year", "area_ha", "area_km2"]]

🌲 Why code this? Derived columns (basal area, biomass, area in ha) and honest handling of missing measurements are everyday inventory tasks — and how you avoid silently wrong totals.

4. Group & summarize¶

groupby answers "for each group, what is ...?" — a core analysis move.

In [ ]:
# total burned area per site
by_site = df.groupby("site")["area_ha"].sum()
print(by_site)

# count of fires per cause
print("\nFires per cause:")
print(df.groupby("cause").size())

🌲 Why code this? groupby answers the questions managers ask: total burned area per region, mean DBH per species, plots per treatment — the heart of a summary report.

✅ Quick check — groupby¶

In words, what does df.groupby("region")["area_ha"].sum() give you?

▶ Show answer The total area_ha for each region — one summed value per group. Swap .sum() for .mean() to get an average.

5. Join two tables¶

Real data is split across tables. merge combines them on a shared key. Here we add a region label per site.

In [ ]:
regions = pd.DataFrame({
    "site":   ["MKRF", "Ambaro"],
    "region": ["British Columbia, Canada", "NW Madagascar"],
})
df = df.merge(regions, on="site", how="left")
df[["site", "region", "year", "area_ha"]].head()

🌲 Forestry example. Field data and lookup tables live apart — plot measurements here, species codes or region names there. merge stitches them so every record carries the labels it needs.

6. Check coordinates & export¶

Before mapping (Chapter 4), confirm latitude/longitude are in valid ranges, then export the cleaned table.

In [ ]:
bad = df[(df["lat"].abs() > 90) | (df["lon"].abs() > 180)]
print("Rows with impossible coordinates:", len(bad))

from pathlib import Path
Path("data").mkdir(exist_ok=True)
out = Path("data") / "fires_clean.csv"
df.to_csv(out, index=False)
print("Wrote", out)

# read it back to prove the round-trip works
again = pd.read_csv(out)
print("Read back", len(again), "rows")

Try it yourself. Compute the average area_ha per year using groupby. Which year burned most on average?

🌲 Why code this? A quick coordinate sanity check catches swapped lat/lon before they wreck a map, and exporting a clean table makes your analysis shareable and reproducible.

Common errors this chapter (and the fix)¶

Message / symptom Likely cause Fix
KeyError: 'speces' column name typo check df.columns
merge gives too few/many rows wrong on= key or duplicates verify the key column matches both tables
a sum ignores some rows missing values (NaN) decide: fillna(...) or dropna(...) and say so
SettingWithCopyWarning assigning into a filtered slice build the column on the full frame, or use .copy()

Bonus 1 — Fast exploring: describe() and value_counts()¶

Why code this? Before analysing, you look. Two one-liners give you the numeric summary and the category counts of any inventory — the first thing a data analyst runs.

In [ ]:
import pandas as pd
df = pd.DataFrame({
    "species": ["fir","cedar","fir","hemlock","fir","cedar"],
    "dbh_cm":  [47.5, 61.0, 28.0, 33.0, 52.0, 40.0],
})
print(df["dbh_cm"].describe())        # count, mean, min, max, quartiles
print()
print(df["species"].value_counts())   # how many plots of each species

🌲 value_counts() instantly tells you the species composition of a stand.

Bonus 2 — Cross-tabs with pivot_table¶

Why code this? Managers love a table of X by Y — mean DBH by species and region. pivot_table builds it in one call.

In [ ]:
import pandas as pd
df = pd.DataFrame({
    "region":  ["MKRF","MKRF","Ambaro","Ambaro","MKRF"],
    "species": ["fir","cedar","mangrove","mangrove","fir"],
    "dbh_cm":  [47.5, 61.0, 20.0, 24.0, 52.0],
})
table = df.pivot_table(values="dbh_cm", index="species",
                       columns="region", aggfunc="mean")
print(table)

🌲 This is the summary table you'd drop straight into a stand or monitoring report.

1. A small fires table¶

We'll reuse the earlier fire records (MKRF + Madagascar) as a DataFrame.

In [ ]:
import pandas as pd, numpy as np
fires = pd.DataFrame({
    "site":   ["MKRF", "MKRF", "Ambaro", "Ambaro", "MKRF"],
    "year":   [2019, 2020, 2019, 2020, 2021],
    "area_ha":[12.5, 3.0, 40.0, 22.0, 7.5],
    "cause":  ["lightning", "human", "human", "lightning", "lightning"],
})
print(fires)

2. groupby with named aggregations¶

Name each output column and the function that fills it — clear and self-documenting.

In [ ]:
g = fires.groupby("site").agg(
    n=("area_ha", "size"),
    total_ha=("area_ha", "sum"),
    mean_ha=("area_ha", "mean"),
)
print(g)

3. pivot_table — sites × causes¶

pivot_table cross-tabulates: one variable down the rows, another across the columns.

In [ ]:
pt = fires.pivot_table(index="site", columns="cause", values="area_ha",
                       aggfunc="sum", fill_value=0)
print(pt)

✅ Quick check — groupby¶

In df.groupby("site").agg(n=("area_ha", "size")), what does n count?

✅ Show answer The number of rows in each site group (fires per site) — size counts rows, including any with missing area.

4. merge — attach a lookup table¶

how="left" keeps every fire row and adds the manager where it matches.

In [ ]:
owners = pd.DataFrame({"site": ["MKRF", "Ambaro"], "manager": ["UBC", "Community"]})
merged = fires.merge(owners, on="site", how="left")
print(merged[["site", "year", "area_ha", "manager"]])

5. Missing data + method chaining¶

Chain operations to read top-to-bottom. .assign adds a column without mutating the original.

In [ ]:
df = fires.copy()
df.loc[1, "area_ha"] = np.nan
print("missing area_ha:", df["area_ha"].isna().sum())

filled = df.assign(area_ha=df["area_ha"].fillna(df["area_ha"].median()))
print("after fill:", filled["area_ha"].tolist())

🌲 Why code this? Field campaigns produce messy tables: gaps, duplicate plots, mixed units. groupby, pivot_table and merge are the daily tools that turn raw plot records into the summaries a forest manager actually reads — area burned per district, mean DBH per stand, volume per owner.
