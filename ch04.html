Chapter 4 — Vector Data with GeoPandas & Shapely

Last week's table had lat/lon columns. GeoPandas turns a table into a GeoDataFrame — a DataFrame with a geometry column of Shapely shapes — so we can filter, measure, join, map, and export real vector data.

Run this notebook in the Python (gem530) environment (GeoPandas installed).

Learning outcomes¶

  1. Build a GeoDataFrame from coordinates and read a vector file.
  2. Inspect geometry, attributes, and the CRS.
  3. Filter by attribute; compute area / length / centroid.
  4. Do one attribute join and one simple spatial join.
  5. Export to a GeoPackage. This is about data handling — not advanced spatial analysis (that's the R course).

1. From a table to points¶

We reuse Week 3's cleaned fires table and make a point per row. GeoPandas uses (x, y) = (lon, lat) and we tag the CRS as WGS84 (EPSG:4326).

In [ ]:
import pandas as pd
import geopandas as gpd

# In the course you would read your Week 3 output:  df = pd.read_csv("data/fires_clean.csv")
# Here we build a small sample so this notebook runs on its own:
df = pd.DataFrame({
    "site":   ["MKRF", "MKRF", "Ambaro", "Ambaro"],
    "cause":  ["lightning", "human", "human", "lightning"],
    "lon":    [-122.57, -122.55, 48.55, 48.60],
    "lat":    [49.27, 49.29, -13.35, -13.40],
    "area_ha":[12.5, 3.0, 40.0, 22.0],
})

gdf = gpd.GeoDataFrame(
    df,
    geometry=gpd.points_from_xy(df["lon"], df["lat"]),
    crs="EPSG:4326",
)
print(type(gdf))
print("CRS:", gdf.crs)
gdf.head()

🌲 Why code this? Your field GPS gives lon/lat columns; turning them into point geometries is the step that lets you map plots, measure distances, and ask 'what falls inside the reserve?'

✅ Quick check — point order¶

To build points from a table, is it points_from_xy(lon, lat) or points_from_xy(lat, lon)?

▶ Show answer points_from_xy(lon, lat) — x = longitude first. Reversing them puts every plot in the wrong place.

5. Geometry measurements¶

area, length, and centroid are computed on the geometry. Important: in a geographic CRS (degrees) these are not real metres — we fix that in Week 5 by reprojecting. For polygons you would use gdf.area; for now we show centroids.

In [ ]:
# centroid of each geometry (for points, the point itself)
gdf["centroid"] = gdf.geometry.centroid
print(gdf[["site", "centroid"]].head())

🌲 Why code this? Area of a cutblock, length of a stream buffer, the centroid of a stand — these drive planning. (Compute them in a projected CRS — that's Week 5.)

✅ Quick check — area units¶

A GeoDataFrame is still in EPSG:4326 (degrees). Is gdf.area a real area in square metres?

▶ Show answer No — in a geographic CRS the number is in square degrees, which is meaningless. Reproject to a projected CRS first (Week 5).

6. Attribute join + one spatial join¶

An attribute join matches on a shared column (like Week 3's merge). A spatial join matches by location — e.g. which region polygon each point falls in.

7. Export¶

Save results as a GeoPackage (.gpkg) — a modern single-file format that keeps the CRS and attributes.

In [ ]:
from pathlib import Path
Path("data").mkdir(exist_ok=True)
gdf.drop(columns=["centroid"]).to_file("data/fires_points.gpkg", driver="GPKG")
print("Wrote data/fires_points.gpkg")

Try it yourself. Filter gdf to the Ambaro site and plot only those points. How many are there?

🌲 Why code this? Exporting a clean GeoPackage means your result opens in QGIS/ArcGIS and re-runs next season — reproducible, shareable geospatial work.

Bonus 1 — Buffers (a riparian zone around a stream)¶

Why code this? A buffer is a zone a fixed distance from a feature — a 30 m riparian reserve along a stream, a setback around a road. It's one of the most-used tools in forest planning. (Buffer in a projected CRS so the distance is real metres.)

In [ ]:
import geopandas as gpd
from shapely.geometry import LineString
stream = gpd.GeoDataFrame(geometry=[LineString([(-122.60, 49.30), (-122.55, 49.32)])],
                          crs="EPSG:4326")
stream_m = stream.to_crs("EPSG:3005")     # BC Albers -> metres
riparian = stream_m.buffer(30)            # 30-metre buffer
print("riparian buffer area (m^2):", round(riparian.area.iloc[0], 1))

🌲 Change 30 to your reserve width — instant riparian zones for any stream layer.

Bonus 2 — "What's inside the reserve?" with a spatial test¶

Why code this? Deciding which plots fall inside a boundary is a core GIS question — within answers it for every feature at once, no clicking.

In [ ]:
import geopandas as gpd
from shapely.geometry import Point, box
plots = gpd.GeoDataFrame(geometry=[Point(-122.57, 49.27), Point(-121.0, 49.0)],
                         crs="EPSG:4326")
reserve = box(-122.75, 49.20, -122.45, 49.40)     # a reserve boundary
inside = plots[plots.within(reserve)]
print("plots inside the reserve:", len(inside), "of", len(plots))

🌲 Swap the box for a real protected-area polygon to audit which plots it contains.
