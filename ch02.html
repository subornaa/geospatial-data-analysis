Chapter 2 — Programming Logic & Reusable Code

Last chapter we stored data in variables, lists, and dictionaries. This chapter we make Python decide and repeat — conditions, loops, and functions — the tools for writing code you can reuse across many coordinates and files.

Learning outcomes¶

  1. Use comparison (> < ==) and logical (and or not) operators.
  2. Write if / elif / else decisions.
  3. Repeat work with for and while loops.
  4. Write functions with parameters and a return value.
  5. Import a module and read its documentation.
  6. Read a traceback and handle errors with try / except. Kernel: Python (gem530).

1. Comparison & logical operators¶

An operator like > returns a boolean (True/False). Logical operators combine booleans. Here we ask: is a point inside a bounding box?

In [ ]:
lat, lon = 49.27, -122.57          # a point in MKRF
# bounding box (min/max) roughly around MKRF
lat_min, lat_max = 49.20, 49.35
lon_min, lon_max = -122.70, -122.45

inside = (lat_min <= lat <= lat_max) and (lon_min <= lon <= lon_max)
print("Inside the box?", inside)

🌲 Why code this? A single comparison like dbh_cm > 50 becomes a rule you apply to a whole inventory — finding every large tree, or every stand steeper than 30°, without reading rows by hand.

2. Conditional statements (if / elif / else)¶

Do different things depending on a condition. Let's label a latitude by zone.

In [ ]:
def_lat = 49.27
if def_lat > 66.5:
    zone = "Arctic"
elif def_lat > 23.5:
    zone = "Temperate"
elif def_lat > 0:
    zone = "Tropical (N)"
else:
    zone = "Southern hemisphere"
print(def_lat, "->", zone)

Try it yourself. Change def_lat to -13.35 (the Madagascar site) and re-run. Which branch executes?

🌲 Forestry example. if/elif sorts data into categories — seedling / sapling / mature by DBH, or low / moderate / high fire risk by fuel load. The computer applies your rules the same way to thousands of records.

3. Loops¶

A for loop repeats once per item. A while loop repeats until a condition is false.

In [ ]:
plot_coords = [(-122.573, 49.271), (-122.569, 49.268), (-122.566, 49.274)]

# for loop: visit every coordinate
for i, (x, y) in enumerate(plot_coords):
    print(f"Plot {i}: lon={x}, lat={y}")

# while loop: a simple countdown
n = 3
while n > 0:
    print("countdown", n)
    n = n - 1

🌲 Why code this? Surveys produce many plots and many files. A loop runs the same step on every one — score 500 plots, read 200 rasters — from code you write once.

✅ Quick check — loops¶

How many times does the body run? for x in [3, 6, 9]:

▶ Show answer 3 — once per item in the list. The values are 3, 6, 9.

4. Functions: reusable code¶

A function packages steps under a name so you can reuse them. It takes parameters and can return a value. This is the most important idea this chapter.

In [ ]:
def is_valid_coord(lat, lon):
    """Return True if lat/lon are within valid Earth ranges."""
    return (-90 <= lat <= 90) and (-180 <= lon <= 180)

print(is_valid_coord(49.27, -122.57))   # True
print(is_valid_coord(120.0, -122.57))   # False: latitude out of range
In [ ]:
def bounding_box(coords):
    """Given a list of (lon, lat), return (min_lon, min_lat, max_lon, max_lat)."""
    lons = [c[0] for c in coords]
    lats = [c[1] for c in coords]
    return (min(lons), min(lats), max(lons), max(lats))

print("BBox:", bounding_box(plot_coords))

Try it yourself. Write a function midpoint(a, b) that takes two (lon, lat) tuples and returns the average point. Test it on two plots.

🌲 Why code this? A function captures a calculation (e.g. basal area from DBH) so you compute it identically everywhere and fix it in one place. Reproducibility starts here.

✅ Quick check — return vs print¶

A function ends with return a + b, but you see nothing on screen when you call it. Why?

▶ Show answer return hands the value back to the caller; it does not print. Do print(add(2, 3)) or store it: total = add(2, 3).

5. Modules & reading documentation¶

import a module, then use its tools. Use help() (or the official docs) to learn what a function expects.

In [ ]:
import statistics
lats = [c[1] for c in plot_coords]
print("Mean latitude:", round(statistics.mean(lats), 5))
# help(statistics.mean)   # uncomment to read the documentation

🌲 Forestry example. The statistics module summarises field measurements; later, geospatial modules do the heavy lifting. Reading the docs is how you pick up a new tool on the job.

6. Errors & debugging¶

Errors are normal. Read the last line of a traceback first — it names the error type. Use try / except to handle problems gracefully.

In [ ]:
from pathlib import Path
try:
    text = Path("does_not_exist.csv").read_text()
except FileNotFoundError:
    print("That file is missing — check the path (see Chapter 5).")

Check inputs before using them — a small guard prevents confusing errors later:

In [ ]:
def safe_report(lat, lon):
    if not is_valid_coord(lat, lon):
        return "Rejected: coordinate out of range"
    return f"OK: {lat}, {lon}"

print(safe_report(49.27, -122.57))
print(safe_report(999, 0))

🌲 Why code this? Field data is messy — missing files, impossible values. try/except and input checks keep a batch job running instead of crashing on plot #347.

Bonus 1 — List comprehensions (loops in one line)¶

Why code this? Filtering and transforming lists is constant in data work; a list comprehension does it in one readable line — you'll use it to pull columns, filter plots, and build inputs for maps.

In [ ]:
dbhs = [1.2, 8.0, 15.5, 42.0, 3.0, 27.5]

# keep only the big trees (DBH > 10) — one line instead of a loop
big = [d for d in dbhs if d > 10]
print("big trees:", big)

# transform: DBH in cm -> radius in cm
radii = [d / 2 for d in dbhs]
print("radii:", radii)

🌲 Same idea you'd use to grab every plot above a threshold, or convert units for a whole column.

Try it yourself. Make a list of only the "mature" DBHs (> 10) rounded to whole numbers.

Bonus 2 — Pairing two lists with zip¶

Why code this? Measurements often arrive in parallel lists (species here, DBH there). zip pairs them up so you can build records — the bridge to the tables you'll meet in Pandas (Chapter 3).

In [ ]:
species = ["Douglas-fir", "redcedar", "hemlock"]
dbhs    = [47.5, 61.0, 28.0]

for sp, d in zip(species, dbhs):
    print(f"{sp}: {d} cm")

# build a list of dictionaries (a mini inventory table)
records = [{"species": sp, "dbh_cm": d} for sp, d in zip(species, dbhs)]
print(records)

🌲 This records list is exactly the shape Pandas turns into a DataFrame next chapter.

1. Functions that return values¶

A good function returns a result you can reuse, rather than only printing it.

In [ ]:
def basal_area(dbh_cm):
    """Basal area (m^2) of a tree from its DBH in cm."""
    radius_m = (dbh_cm / 100) / 2
    return round(3.14159 * radius_m ** 2, 4)

dbhs = [30, 42, 51]
areas = [basal_area(d) for d in dbhs]
print(areas)
print("stand basal area:", round(sum(areas), 4), "m^2")

2. zip and enumerate¶

zip walks two lists together; enumerate gives you a counter for free.

In [ ]:
species = ["Df", "Cw", "Hw"]
dbhs    = [47.5, 61.0, 28.0]
for i, (sp, d) in enumerate(zip(species, dbhs), start=1):
    print(f"{i}. {sp}: {d} cm")

✅ Quick check — zip¶

How many items does list(zip([1, 2, 3], ['a', 'b'])) contain?

✅ Show answer 2 — zip stops at the shorter list, giving [(1,'a'), (2,'b')].

3. Multiple return values + a guard clause¶

A guard clause handles the empty case first, so the rest of the function can assume good input.

In [ ]:
def summarize(values):
    """Return (min, max, mean) — or (None, None, None) if empty."""
    if not values:
        return None, None, None
    return min(values), max(values), round(sum(values) / len(values), 1)

lo, hi, mean = summarize(dbhs)
print("min", lo, "| max", hi, "| mean", mean)
print(summarize([]))

4. A tiny reusable toolkit¶

Group related functions together — this is the seed of your own analysis library.

In [ ]:
def to_feet(m):       return round(m * 3.28084, 1)
def is_big(dbh, k=50): return dbh > k
def classify(dbh):     return "large" if is_big(dbh) else "small"

print(to_feet(40), is_big(61), classify(28))
print([classify(d) for d in dbhs])

🌲 Why code this? Every forestry model — volume, biomass, carbon — is just a stack of small functions like these. Writing them once, with clear names and returns, means your Chapter-11 machine-learning features and your Lab analyses can all call the same tested code.

🌟 Challenge¶

Write big_trees(records, k=50) that returns the list of species whose DBH exceeds k, from a list of (species, dbh) tuples.

🌟 Show one solution 
def big_trees(records, k=50):
    return [s for s, d in records if d > k]

data = [("Df", 47.5), ("Cw", 61.0), ("Hw", 28.0)]
print(big_trees(data))        # ['Cw']
print(big_trees(data, k=25))  # ['Df', 'Cw', 'Hw']
