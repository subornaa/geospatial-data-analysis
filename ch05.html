Chapter 5 — CRS, Files & Data Quality

This chapter makes your spatial data trustworthy: the right coordinate reference system (CRS) so measurements are correct, plus checks for invalid geometry, duplicates, and missing data. These skills are the foundation of Lab 1.

Run in Python (gem530).

Learning outcomes¶

  1. Explain geographic vs projected CRS and inspect/change a CRS.
  2. Reproject and compute correct area/length.
  3. Find and fix invalid geometry, duplicates, and missing data.
  4. Use relative paths and a reproducible folder layout.
  5. Run a small QA checklist function.

1. What CRS is my data in?¶

A geographic CRS (e.g. WGS84, EPSG:4326) uses degrees of lat/lon. A projected CRS (e.g. BC Albers EPSG:3005, or a UTM zone) uses metres — needed for real distances and areas.

In [ ]:
import geopandas as gpd

# In practice: gdf = gpd.read_file("data/fires_points.gpkg")  (your Chapter 4 output).
# Here we build a small MKRF (British Columbia) sample so BC Albers (EPSG:3005) is correct:
gdf = gpd.GeoDataFrame(
    {"site": ["MKRF-1", "MKRF-2", "MKRF-3"]},
    geometry=gpd.points_from_xy([-122.57, -122.55, -122.52], [49.27, 49.29, 49.31]),
    crs="EPSG:4326",
)
print("CRS:", gdf.crs)
print("Is it geographic (degrees)?", gdf.crs.is_geographic)

🌲 Why code this? Knowing whether your data is in degrees or metres decides whether an 'area' means anything. Nearly every geospatial mistake starts with an unchecked CRS.

✅ Quick check — which CRS for area?¶

To compute area in square metres, do you use a geographic CRS (EPSG:4326) or a projected one (EPSG:3005)?

▶ Show answer A projected CRS (e.g. EPSG:3005), whose units are metres. Geographic CRSs use degrees, which don't measure area.

2. Reproject and measure correctly¶

Degrees can't measure area. Reproject to a projected CRS, then measure. For polygons, compare the area before and after to see why this matters.

In [ ]:
# BC Albers (metres) suits the MKRF area; Madagascar would use a UTM zone.
gdf_m = gdf.to_crs("EPSG:3005")
print("New CRS:", gdf_m.crs)
print("Now geographic?", gdf_m.crs.is_geographic)   # False -> metres

# Example with a polygon layer:
# stands = gpd.read_file("data/MKRF/stands.shp")
# print("Area in degrees^2 (wrong):", stands.area.iloc[0])
# print("Area in m^2 (correct):", stands.to_crs(3005).area.iloc[0])

Key idea. Always reproject to a projected CRS before computing area or distance. Reporting an area in "square degrees" is a classic mistake.

🌲 Forestry example. A 40-ha cutblock is 40 ha only in a projected CRS; measured in degrees the number is meaningless. Reproject, then measure — every area/volume estimate depends on it.

3. Data-quality checks¶

Real layers contain invalid geometries, duplicates, and gaps. Find them explicitly.

In [ ]:
# invalid geometries?
invalid = gdf[~gdf.geometry.is_valid]
print("Invalid geometries:", len(invalid))

# a common repair for polygons: buffer(0) or make_valid()
# gdf["geometry"] = gdf.geometry.buffer(0)

# duplicate rows?
print("Duplicate rows:", gdf.duplicated().sum())

# missing attribute values per column
print("\nMissing values per column:")
print(gdf.isna().sum())

🌲 Why code this? Field datasets carry invalid polygons, duplicate plots, and missing values. Catching them in code protects every downstream total and map.

✅ Quick check — QA¶

What does gdf.duplicated().sum() tell you?

▶ Show answer The number of duplicate rows — a quick check for repeated plots. gdf.isna().sum() similarly counts missing values per column.

4. Reproducible paths & folders¶

Use relative paths (from your project folder), not absolute ones like C:/Users/you/..., so the project runs on any machine.

In [ ]:
from pathlib import Path

project = Path.cwd()
data_dir = project / "data"
outputs  = project / "outputs"
outputs.mkdir(exist_ok=True)

print("Project:", project.name)
print("Reading from:", data_dir.name, "| writing to:", outputs.name)

A tidy, reproducible layout:

project/
  data/      raw + cleaned inputs
  outputs/   results you generate
  notebook.ipynb

🌲 Why code this? Relative paths and a tidy data/outputs layout let your analysis re-run on a colleague's machine and next year's data — the definition of reproducible.

5. A reusable QA function¶

Wrap the checks so you can run them on any layer — you will reuse this in Lab 1.

In [ ]:
def quick_qa(gdf, name="layer"):
    """Print a short data-quality report for a GeoDataFrame."""
    print(f"--- QA: {name} ---")
    print("rows:", len(gdf))
    print("CRS:", gdf.crs)
    print("invalid geometries:", (~gdf.geometry.is_valid).sum())
    print("duplicate rows:", gdf.duplicated().sum())
    print("missing values:", int(gdf.isna().sum().sum()))

quick_qa(gdf, "fires_points")

Try it yourself. Add one line to quick_qa that also prints whether the CRS is geographic or projected (hint: gdf.crs.is_geographic).

🌲 Forestry example. A reusable QA function is the checklist you run on every new survey layer before trusting it — consistency you can't get by eye.

Bonus 1 — Real distances (reproject, then measure)¶

Why code this? "How far is each plot from the road?" only has a real answer in metres — i.e. in a projected CRS. This is the everyday reason we reproject.

In [ ]:
import geopandas as gpd
pts = gpd.GeoSeries(
    gpd.points_from_xy([-122.57, -122.50], [49.27, 49.30]), crs="EPSG:4326"
).to_crs("EPSG:3005")                      # -> metres
d = pts.iloc[0].distance(pts.iloc[1])
print("distance between the two plots:", round(d), "m")

🌲 In degrees this number would be meaningless; in a projected CRS it's real metres.

Bonus 2 — Repairing an invalid polygon¶

Why code this? Digitised stand boundaries often self-intersect ("bow-ties"), which breaks area and overlay tools. A one-line repair rescues them.

In [ ]:
import geopandas as gpd
from shapely.geometry import Polygon
bowtie = Polygon([(0, 0), (2, 2), (2, 0), (0, 2)])   # self-intersecting
gdf = gpd.GeoDataFrame(geometry=[bowtie], crs="EPSG:3005")
print("valid before?", bool(gdf.is_valid.iloc[0]))
gdf["geometry"] = gdf.buffer(0)                      # common repair
print("valid after? ", bool(gdf.is_valid.iloc[0]))

🌲 Run this before any area calculation on messy boundary data.

  • pyproj — the CRS engine behind .to_crs. You rarely call it directly; know it is doing the reprojection. See the Package Guide.

Working with AI (30-second habit)¶

AI often forgets the CRS. When AI gives you reprojection or area code, verify: (1) the source CRS is set, (2) you reproject before measuring, (3) the result units make sense (metres, not degrees).

1. Area needs a projected CRS¶

Measuring area in degrees is meaningless. Reproject to metres first.

In [ ]:
import geopandas as gpd
from shapely.geometry import Polygon
stand = gpd.GeoDataFrame({"id": [1]}, geometry=[Polygon(
    [(-122.6, 49.2), (-122.5, 49.2), (-122.5, 49.3), (-122.6, 49.3)])], crs="EPSG:4326")
print("area in degrees^2 (meaningless):", round(stand.area.iloc[0], 6))

stand_m = stand.to_crs(3005)               # BC Albers, metres
print("area in ha (correct):", round(stand_m.area.iloc[0] / 10_000, 1))

✅ Quick check — CRS¶

You need the area of a harvest block in hectares. Do you compute it in EPSG:4326 (degrees) or EPSG:3005 (metres)?

✅ Show answer EPSG:3005 (a projected, metre-based CRS). Area in degrees is not a real area — always .to_crs() to a projected CRS first.

2. Invalid geometries¶

A self-intersecting ("bow-tie") polygon breaks many operations. buffer(0) is a classic repair.

In [ ]:
from shapely.geometry import Polygon
bowtie = Polygon([(0, 0), (2, 2), (2, 0), (0, 2)])   # self-intersecting
print("valid?", bowtie.is_valid)
fixed = bowtie.buffer(0)
print("fixed valid?", fixed.is_valid, "| area:", round(fixed.area, 2))

3. Round-trip to a GeoPackage¶

Write to disk and read back to confirm the CRS and rows survive. We use a temporary folder so nothing clutters your course folder.

In [ ]:
import tempfile, os
folder = tempfile.mkdtemp()
path = os.path.join(folder, "stand.gpkg")
stand_m.to_file(path, driver="GPKG")
back = gpd.read_file(path)
print("re-read CRS:", back.crs.to_epsg(), "| rows:", len(back))

🌲 Why code this? A wrong CRS is the single most common geospatial bug — and it silently gives areas that are off by orders of magnitude. Checking validity and re-reading what you wrote is how you make a mangrove-loss or harvest-area number you can defend.
