Chapter 9 — Raster Data with NumPy & Rasterio

Vector data was points and polygons. Raster data is a grid of cells — elevation, satellite bands, land cover. The key idea: a raster band is a NumPy array. Rasterio reads/writes the georeferenced files; NumPy does the math; Matplotlib displays it.

Run in Python (gem530). The NumPy cells run anywhere; the Rasterio cells need a raster file (provided) and the gem530 environment.

Learning outcomes¶

  1. Describe raster structure: bands, rows, columns, cells, NoData.
  2. Read a raster band into a NumPy array and inspect metadata.
  3. Do array math, masking, and simple reclassification.
  4. Compute a simple index (e.g. a difference or NDVI).
  5. Write a GeoTIFF and display it with Matplotlib.

1. A raster is an array¶

Let's build a tiny synthetic elevation raster (4×4) so the NumPy ideas are concrete. 255 marks NoData (cells with no valid value).

In [ ]:
import numpy as np

band = np.array([
    [10, 12, 15, 255],
    [11, 13, 14, 255],
    [ 9, 10, 255, 255],
    [ 8,  9, 10, 11],
], dtype=float)

print("shape (rows, cols):", band.shape)
print("min/max (incl. NoData):", band.min(), band.max())

🌲 Why code this? Elevation, canopy height, burn severity, satellite bands — all arrive as grids. Seeing a raster as an array is what lets you compute on millions of forest pixels at once.

2. Handle NoData with a mask¶

Replace the NoData value with np.nan so it doesn't corrupt statistics.

In [ ]:
nodata = 255
masked = np.where(band == nodata, np.nan, band)
print("mean elevation (NoData ignored):", round(np.nanmean(masked), 2))

🌲 Forestry example. Cloud, shadow and off-image pixels are NoData. Masking them is why your mean canopy height describes the forest, not the holes in the data.

✅ Quick check — NoData¶

Why replace a NoData value (255) with np.nan before averaging?

▶ Show answer NoData isn't a measurement — leaving 255 in would drag the mean upward. Mask it, then use np.nanmean() so only real pixels count.

3. Array math & reclassification¶

Operations apply to every cell at once. Here we reclassify into low/high zones.

In [ ]:
# add 100 m to every valid cell (array math)
raised = masked + 100
print(raised)

# reclassify: 1 = low (<12), 2 = high (>=12); NoData stays NaN
reclass = np.where(np.isnan(masked), np.nan, np.where(masked < 12, 1, 2))
print("\nReclassified:\n", reclass)

🌲 Why code this? Reclassifying continuous values into classes — low/moderate/high burn severity, slope classes — is how raw measurements become management categories.

4. A simple index (NDVI)¶

Vegetation indices combine bands. NDVI = (NIR − Red) / (NIR + Red). With two small synthetic bands:

In [ ]:
red = np.array([[0.20, 0.22], [0.19, 0.25]])
nir = np.array([[0.40, 0.55], [0.38, 0.60]])
ndvi = (nir - red) / (nir + red)
print("NDVI:\n", np.round(ndvi, 3))

🌲 Forestry example. NDVI turns raw bands into a vegetation-vigour map: the workhorse index for monitoring forest health, drought stress and regrowth after harvest or fire.

5. Read a real raster with Rasterio¶

The real workflow: open a GeoTIFF, read a band into an array, and inspect its georeferencing (CRS, transform, NoData).

In [ ]:
import rasterio
from rasterio.transform import from_origin
from pathlib import Path
Path("data").mkdir(exist_ok=True)

# In practice you would open a provided raster (e.g. SRTM over MKRF). Here we
# create a small demo GeoTIFF so the notebook runs on its own:
demo = np.random.default_rng(0).normal(300, 50, (30, 30)).astype("float32")
demo[0:3, 0:3] = -9999.0
with rasterio.open("data/demo_elev.tif", "w", driver="GTiff", height=30, width=30,
                   count=1, dtype="float32", crs="EPSG:4326",
                   transform=from_origin(-122.75, 49.40, 0.01, 0.01), nodata=-9999.0) as dst:
    dst.write(demo, 1)

with rasterio.open("data/demo_elev.tif") as src:
    elev = src.read(1)              # band 1 -> a NumPy array
    print("shape:", elev.shape, "| CRS:", src.crs, "| NoData:", src.nodata)
    profile = src.profile           # keep georeferencing for writing later

🌲 Why code this? Rasterio keeps pixels tied to real-world coordinates. Without the CRS and transform your result is a picture; with them it's a map you can overlay on stands and roads.

✅ Quick check — Rasterio¶

What does src.read(1) give you?

▶ Show answer Band 1 as a NumPy array. The dataset object also carries src.crs, src.transform and src.nodata.

6. Write a result back to a GeoTIFF¶

Compute something, then save it with the same georeferencing so it lines up in any GIS.

In [ ]:
# reclassify the raster we read (elev) and write it out with the SAME profile
elev_masked = np.where(elev == -9999.0, np.nan, elev)
elev_reclass = np.where(np.isnan(elev_masked), -9999.0,
                        np.where(elev_masked < 300, 1, 2)).astype("float32")

Path("outputs").mkdir(exist_ok=True)
profile.update(dtype="float32")            # reuse CRS + transform from the source
with rasterio.open("outputs/elev_reclass.tif", "w", **profile) as dst:
    dst.write(elev_reclass, 1)

with rasterio.open("outputs/elev_reclass.tif") as chk:   # re-open to confirm
    print("wrote + re-opened:", chk.read(1).shape, "| CRS kept:", chk.crs)

🌲 Why code this? Writing results back to GeoTIFF (same georeferencing) is how your analysis becomes a layer a colleague opens in QGIS or ArcGIS.

Symptom Cause Fix
statistics look wrong NoData included mask to np.nan, use np.nanmean
ValueError: operands could not be broadcast arrays different shapes check arr.shape before combining
output won't line up in GIS wrote without the profile reuse src.profile when writing
all-black / all-white image one extreme value stretches the colours mask NoData before plotting

🎓 Additional learning (optional)¶

Bonus 1 — From pixel counts to hectares¶

Why code this? Managers ask "how many hectares burned?", not "how many pixels?". With a known pixel size the conversion is one line — and it's how burn/harvest areas get reported.

In [ ]:
import numpy as np
cls = np.array([[1, 2, 3], [2, 3, 3], [1, 1, 2]], dtype=float)
pixel_m = 30                          # Landsat pixels are 30 x 30 m
area_ha_per_pixel = (pixel_m * pixel_m) / 10_000     # m2 -> hectares
for k in (1, 2, 3):
    n = int(np.nansum(cls == k))
    print(f"class {k}: {n} pixels = {n * area_ha_per_pixel:.2f} ha")

Bonus 2 — Zonal statistics (a value inside a zone)¶

Why code this? "What's the mean NDVI inside this stand?" is the classic zonal question — a boolean mask plus np.nanmean answers it.

In [ ]:
import numpy as np
ndvi = np.array([[0.2, 0.6, 0.7], [0.3, 0.8, 0.9], [0.1, 0.4, 0.5]])
stand = np.array([[False, True, True], [False, True, True], [False, False, False]])
inside = np.where(stand, ndvi, np.nan)
print("mean NDVI inside the stand:", round(np.nanmean(inside), 3))
print("mean NDVI overall        :", round(np.nanmean(ndvi), 3))

🌲 Swap the boolean mask for a rasterised stand boundary and this is production zonal stats.

1. NDVI — vegetation from two bands¶

NDVI = (NIR − Red) / (NIR + Red). NumPy applies it to whole arrays at once.

In [ ]:
import numpy as np
red = np.array([[0.20, 0.30], [0.25, 0.28]])
nir = np.array([[0.50, 0.45], [0.60, 0.40]])
ndvi = (nir - red) / (nir + red)
print(np.round(ndvi, 3))

2. Masking NoData¶

Sentinel values like -9999 must be excluded, or they wreck your statistics.

In [ ]:
elev = np.array([[110, 112, -9999], [108, -9999, 111]], dtype=float)
masked = np.where(elev == -9999, np.nan, elev)
print("mean ignoring NoData:", round(np.nanmean(masked), 1))

✅ Quick check — NoData¶

Why use np.nanmean instead of np.mean after masking NoData to np.nan?

✅ Show answer np.mean returns nan if any value is nan; np.nanmean skips the NaNs and averages the real pixels.

3. Reclassify + terrain gradient¶

Threshold the elevation into classes, and use np.gradient for a simple slope-direction read.

In [ ]:
recl = np.where(np.isnan(masked), np.nan, np.where(masked < 110, 1, 2))
print("reclassified:\n", recl)

dem = np.array([[1., 2, 3], [2, 3, 4], [3, 4, 5]])
dz_dy, dz_dx = np.gradient(dem)
print("gradient in x:\n", dz_dx)

4. Write a raster in memory¶

MemoryFile lets you create and read a GeoTIFF without touching disk — great for tests and pipelines.

In [ ]:
import rasterio
from rasterio.io import MemoryFile
from rasterio.transform import from_origin
arr = np.nan_to_num(recl, nan=0).astype("float32")
with MemoryFile() as mem:
    with mem.open(driver="GTiff", height=arr.shape[0], width=arr.shape[1], count=1,
                  dtype="float32", crs="EPSG:3005",
                  transform=from_origin(0, 10, 10, 10)) as ds:
        ds.write(arr, 1)
    with mem.open() as ds:
        print("read back:", ds.read(1).shape, "| CRS:", ds.crs.to_epsg())

🌲 Why code this? Band math turns raw satellite bands into meaning — NDVI for greenness, NBR for burn severity. Masking NoData keeps cloud and edge pixels out of your averages. These array moves are the whole of raster analysis, whether the grid is elevation, canopy height, or a Landsat scene.
