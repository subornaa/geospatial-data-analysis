The end-to-end pipeline (Weeks 1–5 in one flow)¶

Table → clean (Pandas) → points (GeoPandas) → reproject & QA (CRS) → summarize → export. Read each step and notice which week taught it.

import pandas as pd
import geopandas as gpd
from pathlib import Path

# 1) TABLE (Week 3): load and clean
# In the course: df = pd.read_csv("data/fires_clean.csv"). Small MKRF sample here:
df = pd.DataFrame({
    "site":   ["MKRF-N", "MKRF-N", "MKRF-S", "MKRF-S"],
    "lon":    [-122.57, -122.55, -122.52, -122.50],
    "lat":    [49.31, 49.32, 49.27, 49.28],
    "area_ha":[12.5, 3.0, 40.0, 22.0],
})
df = df.dropna(subset=["lat", "lon"])            # need coordinates to map

# 2) POINTS (Week 4): build a GeoDataFrame
gdf = gpd.GeoDataFrame(
    df, geometry=gpd.points_from_xy(df["lon"], df["lat"]), crs="EPSG:4326"
)

# 3) CRS + QA (Week 5): reproject, then check quality
gdf_m = gdf.to_crs("EPSG:3005")
print("invalid geometries:", (~gdf_m.geometry.is_valid).sum())
print("duplicate rows:", gdf_m.duplicated().sum())

# 4) SUMMARIZE (Week 3): area burned per site
print(gdf_m.groupby("site")["area_ha"].sum())

# 5) EXPORT (Weeks 4–5): reproducible output
Path("outputs").mkdir(exist_ok=True)
gdf_m.to_file("outputs/fires_bcalbers.gpkg", driver="GPKG")
print("Wrote outputs/fires_bcalbers.gpkg")

Debugging clinic — the usual suspects¶

When something breaks, check these first (each maps to a week):

  1. Path wrong / absolute → Week 5 (use relative paths).
  2. CRS missing or mismatched → Weeks 4–5 (gdf.crs, .to_crs).
  3. Merge key wrong → Week 3 (check the on= column and row counts).
  4. Missing values → Week 3 (isna().sum(), decide fill vs drop).
  5. (lon, lat) reversed → Weeks 1 & 4 (x = longitude first).

Real forest analyses are never one command — they're a chain: table → clean → map → reproject → summarise → export. Most errors happen between the steps, not inside them. Today you practise the joins between steps, which is exactly what Lab 1 (and your project) will ask for.

🎓 Additional learning (optional)¶

Bonus — Wrap the whole pipeline in one reusable function¶

Why code this? Once a workflow works, package it. Next season's survey becomes a one-line call instead of a re-run of twenty cells — the difference between a script and a tool.

In [ ]:
import pandas as pd, geopandas as gpd
from pathlib import Path

def plots_to_gpkg(df, out_path, to_crs="EPSG:3005"):
    """Table with lon/lat -> cleaned, reprojected GeoPackage. Returns the GeoDataFrame."""
    df = df.dropna(subset=["lon", "lat"])
    gdf = gpd.GeoDataFrame(df, geometry=gpd.points_from_xy(df["lon"], df["lat"]),
                           crs="EPSG:4326").drop_duplicates()
    gdf = gdf.to_crs(to_crs)
    Path(out_path).parent.mkdir(exist_ok=True, parents=True)
    gdf.to_file(out_path, driver="GPKG")
    return gdf

demo = pd.DataFrame({"site": ["A", "B"], "lon": [-122.57, -122.55], "lat": [49.27, 49.29]})
result = plots_to_gpkg(demo, "outputs/demo_plots.gpkg")
print("rows:", len(result), "| CRS:", result.crs)

🌲 Reuse this on any new plot table — the same five steps, one call.
