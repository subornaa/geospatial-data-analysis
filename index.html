Geospatial Data Analysis with Python

Python programming for geospatial data handling, processing, visualization & workflow automation

An open educational resource · Dr. Suborna Ahmed · UBC Faculty of Forestry & Environmental Stewardship

About this book

This open educational resource teaches Python programming for geospatial data analysis, starting from no assumed programming experience. You'll learn Python fundamentals with small geospatial examples, then work with tabular, vector, and raster data; automate GIS tasks; produce clear maps; and finish with an introduction to machine learning on satellite imagery.

Two environmental datasets recur throughout: the Malcolm Knapp Research Forest in British Columbia and the mangrove coast of northwest Madagascar, alongside Landsat imagery.

How to use this book

  • Each chapter is a hands-on lesson: read the explanation, run the code, and try the Quick check and Try it yourself prompts (answers are collapsible).
  • Most chapters run in an open-source Python environment (Pandas, GeoPandas, Shapely, Rasterio, NumPy, Matplotlib, scikit-learn). Two chapters use ArcPy, which requires ArcGIS Pro.
  • Each chapter ends with practice exercises to work through on your own.

About the author

Dr. Suborna Ahmed — Associate Professor of Teaching, Department of Forest Resources Management, Faculty of Forestry & Environmental Stewardship, University of British Columbia. She teaches data analytics, computing, forest biometrics, and quantitative methods for forestry and natural-resources students, and develops open educational resources using real forestry datasets.
